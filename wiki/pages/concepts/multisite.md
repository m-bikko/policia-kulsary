# Много лендингов (мультисайт)

С 2026-10-02 сайт - не одна страница Жылыоя, а **портал лендингов полиции всего Казахстана**: у каждой из 20 областей (17 областей + Астана, Алматы, Шымкент) и у каждого района/города внутри них свой лендинг общего дизайна ([[taplink-page]]). Решения заказчика: один общий PIN, уровни «области и районы», корень - портал с картой.

## Адреса

| Адрес | Что |
|---|---|
| `/` | выбор языка ([[splash-language-select]]) |
| `/kz` | портал с картой «Найдите полицию своего района» ([[portal-directory]]) |
| `/kz/atyrau` | лендинг департамента области |
| `/kz/atyrau/zhylyoi` | лендинг районного управления |

Slug-и берутся из [[kz-map]] и стабильны (пересборка карты их не меняет - скрипт проверяет). Старый адрес Жылыоя `/kz` теперь портал: ссылки в соцсетях нужно заменить на `/kz/atyrau/zhylyoi`.

## Наследование от шаблона

- Документ `template` хранит всё общее: подписи кнопок, заголовки секций, общенациональные тексты (приём на службу, системы отслеживания), логотип МВД.
- Документ лендинга хранит только своё. `inheritFromTemplate(template, site)`: пустой текст/фото → значение шаблона; переводимое поле - **по каждому языку отдельно**; объект - рекурсивно; список - целиком (свой непустой список заменяет шаблонный).
- `SITE_FIELDS` (`split.ts`) - поля, которые по смыслу у каждого свои; в редакторе лендинга по умолчанию видны только они. `splitSiteContent` разделил прежний единый контент Жылыоя на шаблон и лендинг без потерь (проверено обратной сборкой).

## Публикация

- Все лендинги созданы черновиками (`pnpm db:content`) с географическим названием в `header.name` и областью в `header.department`. Черновик не виден публично (RLS) и отдаёт 404.
- Публикация - переключатель в [[content-editor]]. Портал и лендинг области начинают показывать ссылку сразу (`updateTag`).
- Пустой опубликованный лендинг выглядит аккуратно: пустые секции скрыты, общие тексты пришли из шаблона.

## На заметку

- В шаблоне лежат 4 устройства «Системы отслеживания» (дрон, «Кибер шериф», Ekin Patrol G2, «Оракул-Инсайт») - они показываются на всех лендингах. Если какие-то из них есть только в Жылыое, их нужно перенести в собственный список Жылыоя (режим «Все поля»).
- Района Туран (Шымкент) нет в OSM - на карте и в списках его нет.
- После деплоя удалить строку `main` (её читает только старая версия сайта).
