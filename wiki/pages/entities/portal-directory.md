# Портал с картой

Страница `/kz|/ru|/en` - «Найдите полицию своего района». Сюда ведёт [[splash-language-select]] и ссылки «Все подразделения» с лендингов ([[multisite]]).

- Шапка: логотип из шаблона, тема, язык (сохраняет выбранную область в якоре), заголовок и подзаголовок, кнопка **102**.
- [[kz-map|Карта]]: регионы, где есть опубликованный лендинг, подсвечены; клик - зум в область и её районы; клик по опубликованному району - переход на лендинг, по черновику - подсветка строки «готовится» в списке.
- Панель: поиск по трём языкам; без запроса - список областей (золотая точка = есть лендинги), в области - «Департамент полиции области» и районы (опубликованные первыми).
- Тексты - документ `portal` (секции `directory`, `meta`, `theme`) на трёх языках, редактируются в [[content-editor]] (`/edit/portal`).
- ISR: статусы публикации приходят с сервера, страница перегенерируется после публикации.
- `not-found.tsx` рядом - 404 на трёх языках с кнопками на портал (для черновиков и неверных адресов).
